# Multiple Of 100

## Problem Description

This project contains a Java program that reads an integer entered by the user and determines whether it is a multiple of 100.

## solution

1. Read an integer from the user.
2. Divide the number by 100.
3. Check if the remainder is equal to 0
4. Print **multiple of 100** if true.
5. Otherwise, print **not multiple of 100**.


## Example Execution

### Example 1

**Input**

12000

**Output**

multiple of 100

### Example 2

**Input**

593

**Output**

not multiple of 100
